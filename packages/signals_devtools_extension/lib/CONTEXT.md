# Signals DevTools Extension API

This directory contains the entry points for the Signals DevTools extension.

## Entry Points

### [main.dart](file:///Users/rodydavis/Developer/signals.dart/packages/signals_devtools_extension/lib/main.dart)
The main entry point for the Flutter application when running as a DevTools extension.

### [src/](file:///Users/rodydavis/Developer/signals.dart/packages/signals_devtools_extension/lib/src/CONTEXT.md)
Contains the core implementation of the extension:
- **signals_devtools_extension.dart**: The root widget of the extension UI.
- **nodes_state.dart**: The bridge between the UI and the running app's service extensions.
