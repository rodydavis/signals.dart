# Signals Examples

A collection of projects demonstrating how to use Signals in different environments and architecture patterns.

## Category: Flutter

### Core UI Patterns
- **[flutter_counter](file:///Users/rodydavis/Developer/signals.dart/examples/flutter_counter/)**: The classic counter app using `Watch` and `SignalsMixin`.
- **[shopping_cart](file:///Users/rodydavis/Developer/signals.dart/examples/shopping_cart/)**: A more complex state management example with multiple signals and business logic.
- **[infinite_scroll](file:///Users/rodydavis/Developer/signals.dart/examples/infinite_scroll/)**: Demonstrates `FutureSignal` and scroll integration.

### Animations & Graphics
- **[animations_example](file:///Users/rodydavis/Developer/signals.dart/examples/animations_example/)**: Using `TickerSignal` for high-performance animations.
- **[flutter_colorband](file:///Users/rodydavis/Developer/signals.dart/examples/flutter_colorband/)**: Graphic-heavy visualization driven by reactive state.

### Architecture & Integrations
- **[clean_architecture](file:///Users/rodydavis/Developer/signals.dart/examples/clean_architecture/)**: Real-world application of signals in a layered architecture.
- **[mvi_example](file:///Users/rodydavis/Developer/signals.dart/examples/mvi_example/)**: Implementation of the Model-View-Intent pattern.
- **[auth_flow](file:///Users/rodydavis/Developer/signals.dart/examples/auth_flow/)**: Navigation and authentication state management.
- **[get_it_signals](file:///Users/rodydavis/Developer/signals.dart/examples/get_it_signals/)**: Combining signals with the `get_it` service locator.
- **[drift_example](file:///Users/rodydavis/Developer/signals.dart/examples/drift_example/)**: Reactive database integration with `Drift`.

## Category: Pure Dart & CLI

- **[dart_examples](file:///Users/rodydavis/Developer/signals.dart/examples/dart_examples/)**: Basic CLI and logic-only examples.
- **[dart_mappable_example](file:///Users/rodydavis/Developer/signals.dart/examples/dart_mappable_example/)**: Integration with code generation.
- **[rxdart](file:///Users/rodydavis/Developer/signals.dart/examples/rxdart/)**: Comparison and bridging between RxDart and Signals.

## Category: Web & Experimental

- **[html_canvas](file:///Users/rodydavis/Developer/signals.dart/examples/html_canvas/)**: Using signals with raw HTML5 Canvas.
- **[html_todo_app](file:///Users/rodydavis/Developer/signals.dart/examples/html_todo_app/)**: A vanilla JS-style Todo app built with Dart and Signals.
- **[node_based_editor](file:///Users/rodydavis/Developer/signals.dart/examples/node_based_editor/)**: A complex, reactive graph editor.
