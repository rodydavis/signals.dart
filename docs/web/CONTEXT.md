# Jaspr Docs Static Assets

This directory contains public-facing assets, raw markdown source documents, and machine-readable context files for the documentation website.

## Assets & Configurations

- **`favicon.ico` / `favicon.svg`**: The browser tab page icon assets.
- **`llms.txt` / `llms-full.txt`**: Complete, consolidated raw text representations of all packages and guides, optimized for consumption by Large Language Models (LLMs) and context retrieval systems.
- **[images/](file:///Users/rodydavis/.gemini/antigravity/worktrees/signals.dart/build-signals-reactive-framework/docs/web/images/)**: Images, diagrams, logo variants, and graphics used in documentation articles.
- **[raw_markdown/](file:///Users/rodydavis/.gemini/antigravity/worktrees/signals.dart/build-signals-reactive-framework/docs/web/raw_markdown/)**: The raw repository markdown files that serve as source content for the static Jaspr site engine.
